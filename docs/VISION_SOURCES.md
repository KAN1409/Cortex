# Vision implementation references

- ML Kit Text Recognition v2: Latin / Chinese / Devanagari / Japanese / Korean scripts; no Arabic-script recognizer.
- Tesseract4Android 4.9.0 wraps Tesseract 5.5.1 and supports Android API 21+ with traineddata stored in app-readable private storage.
- Arabic model: tesseract-ocr/tessdata_fast tag 4.1.0, `ara.traineddata`.
